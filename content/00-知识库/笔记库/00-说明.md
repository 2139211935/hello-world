# 笔记库 · 使用说明

本库存放**主题索引**：按**一个主题/角度**，把分散在 `00-知识库/原子库/` 的原子分点**索引**出来——**只列不展开、不做叙事成文**。它是三库中的"导航层" —— 原子点是内容本体，概念页把原子点按"属于谁"装箱，本库把原子点按"哪个主题"拢到货架上。

> [!warning] 主题索引 ≠ 概念 —— 分界铁律
> - **概念（概念库）＝名词本体/分类锚点**：一个既定**名词**（如 特征阻抗、反射、串扰），只**聚合导航**，**不写叙事正文**。回答"这个概念有哪些点"。
> - **主题索引（本库）＝聚合入口/货架**：按一个**主题/角度**把相关原子点**列出来**，**只列不展开**。回答"这个主题拢了哪些点"。讲清道理靠原子点自身的"讲懂型正文"与概念聚合，**不再额外写一篇连贯文章**。
> - **命名规则**：概念名必须是**名词**；出现"为什么/如何/为什么需要/是什么"等疑问句或叙事句式 → **不是概念，是索引小节**，进本库的目录/索引页，不做概念、也不写展开成文。
> - **不同层、不同轴**：概念是"静态名词"，主题索引是"聚合入口"。概念页不说"从……到……"的故事；主题索引**不是**叙事文章，只做导航。
> - 口诀：**这是"一个东西/名词"还是"一个主题的货架"？** 前者去概念库，后者来本库；名词用名词命名，主题货架按主题列点（不展开）。

## 三层三库架构

| 层 | 库 | 一个文件= | 聚合轴 | 聚合机制 |
|----|----|----------|--------|----------|
| 原子 | `00-知识库/原子库/` | 一个知识点 | 无 | `concept` 字段 → 概念（必填，物理解耦） |
| 概念 | `00-知识库/概念库/` | 概念 MOC | 概念轴 | dataview `WHERE concept` 自动聚合 | 
| 主题索引 | `00-知识库/笔记库/` | 一个主题的货架 | 主题轴（可跨概念） | 只列相关原子点 + dataview 可视化 |

## 核心机制

1. **重内聚两种轴**：概念页按"概念"聚（自动）；主题索引按"主题"列（只列不展开），**可跨多个概念**。
2. **只列不写**：主题索引（目录/索引页）只把该主题串到的 `[[原子点]]`/`[[概念]]` 按主题顺序列出来，不做叙事成文、不展开正文；讲清道理靠原子点自身的"讲懂型正文"与概念聚合承担。
3. **索引可视化**：索引页可嵌一个 dataview 块，列出它实际索引的 `[[原子点]]`，让"这个主题用了哪些点"一目了然。

## 命名

- 每个主题文件夹的目录文件统一命名 `000-目录.md`（`000` 专指目录，排序最前）。
- 主题索引页文件 = 主题名（不必带序号），目录条目按主题/章节顺序列出本主题相关原子点，`[[原子点]]`/`[[概念]]` 只列不展开、无篇幅要求。

## frontmatter 字段

```yaml
---
type: 索引
主题: <主题/角度 一句话>
日期: 2026-09-01
状态: 待完善        # 待完善 / 进行中 / 已完善
tags: []
---
```

## 主题索引骨架（不算正文要求，仅防散乱）

1. `# 标题`（如 `# 概率论的基本概念`，可带主题序号）+ `> [!info] 索引定位` —— 从什么主题角度、拢了哪些概念。
2. `## 用到的原子点（按顺序）` —— 开篇把本主题将索引的全部 `[[原子点]]`/`[[概念]]` 按顺序列出，只列不展开，定下货架。
3. `## 本索引用到的原子点` —— dataview 列出实际索引的点（可视化）。
4. `## 相关概念` —— 这本索引跨到的概念。
5. `## 同类主题` —— 相邻主题索引互链。

## 概念页联动

概念 MOC 页的反链块会自动列出**引用了本概念的索引与主题页**，所以索引页里凡提到某概念用 `[[概念名]]` 引用即可被跨库反链到。
