气体分子的平均自由程

一句话定义

平均自由程 λ 是气体分子在两次连续碰撞之间自由飞行的平均路程，用来量度分子碰撞的频繁程度。

定性

先把这个”自由飞行”看个清楚。

前面说过，室温氧分子平均每秒飞 480 米，快得像高铁。可你若真的”盯住”一个分子，会发现它根本没机会跑远——它刚飞出去没几步，就”砰”地撞上另一个分子，换个方向；再飞几步又撞，再换方向。它走出来的不是一条直线，而是一段密密麻麻的锯齿折线，像被弹来弹去的小钢珠。每一次两段碰撞之间，它曾自由地、不被打扰地飞行过一段距离，这段距离叫自由程；把所有分子所有自由程平均起来，就是平均自由程 λ。

所以平均自由程是一把度量”分子有多容易撞”的尺子：λ 长，说明分子能飞得远、很少撞；λ 短，说明分子挤得很密、一步一撞。它回答的不是”分子多快”，而是”分子撞得多频繁、能走多远不被打断”。

它在体系里的位置：平均自由程是气体动理论走向输运现象的那座桥。后面要讲的扩散、黏性、热传导，全都靠分子”撞来撞去传递质量和能量”——而传得快慢，正取决于分子能在不撞的情况下走多远，也就是 λ。没有 λ，就无法估算气体输运的快慢。

反直觉的点：分子速度极快（每秒几百米），但扩散却极慢（香水要飘几分钟才闻得到）。为什么？因为分子速度快，却几乎每走几十纳米就撞一次、被迫转向，于是它在宏观上的”净位移”被疯狂碰撞拖慢。快，是被碰撞的”快”；慢，是被折线绕晕的”慢”——这一对反差正是 λ 与碰撞频率联手造成的。

图：分子在两两碰撞之间走直线，碰撞后随机换向，形成锯齿折线；相邻两碰撞点间的直线段为自由程，其平均值即平均自由程 λ。

数学表达

平均自由程 λ 与碰撞频率 Z 的核心关系：

λ=Zvˉ​,Z=2​πd2nvˉ⇒λ=2​πd2n1​

各符号：vˉ 是分子平均速率，Z 是平均碰撞频率（每秒每个分子碰撞次数），d 是分子有效直径（把分子当硬球的直径），n 是分子数密度。

由 n 用物态方程换成压力、温度（p=nkT），得与宏观量的关系：

λ=2​πd2pkT​

符号：k 是玻耳兹曼常数，T 是温度，p 是压强。这两个式子更实用：等温下 λ∝1/p；等压（等 n）下 λ∝T/p。

读这个结构：λ 分子是 1、分母是 2​πd2n。πd2 是一个分子的”碰撞截面”（直径 d 圆盘的面积）；n 是”有多密”；2​ 是”其它分子也在动的相对修正”。截面越大、分子越密，λ 越小——三者共同决定分子能自由飞多远。

关键性质

  • λ 与分子数密度 n 成反比。 n 大则 λ 小。为什么：分子越密，单位时间内能撞上的分子越多，平均每两次碰撞间的自由距离越短。这解释了为何压缩气体（n 升）时碰撞更频繁。

  • λ 与有效直径平方 d2 成反比。 分子越大、碰撞截面 πd2 越大，越易撞。为什么：把分子看作半径为 d/2 的硬球，只要两分子中心的距离小于 d 就碰撞；d 越大，碰撞的机会区间越宽。

  • 2​ 来自其它分子的相对运动。 为什么要乘 2​：因为分析时不能假设其它分子静止——它们也在乱飞，所以目标分子相对其它分子的”相对平均速率”是 2​vˉ，比单个分子速率 vˉ 大。这个 2​ 就是相对运动带来的碰撞增强。

  • 常温常压下 λ 极小、Z 极大。 空气在 300 K、1 atm 下 λ∼10−7 m（约几十纳米），Z∼109 s−1（每秒几十亿次碰撞）。为什么：分子数密度 n∼2.5×1025 m−3 海量、分子千亿次相撞，导致自由程被压到纳米级。

  • λ∝T/p。 增大温度、降低压强都让 λ 变大。为什么：T 高则分子热运动快、碰撞间隙……（准确说 p 小则 n 小、λ 大；T 高则分子速率大、Z 略增，但主导是 n 与 d2）。工程常以”真空度”控 p 来放大 λ。

推导

现在把 λ=2​πd2n1​ 真正推出来——不是背公式，而是从”一个分子扫过的圆柱”看起。

先抛问题：一个分子飞过一段路，途中会撞上多少个分子？这些碰撞把它的”自由程”压到什么程度？那个 2​ 和 1/2​ 又从哪来？

设物理场景。取理想气体，分子数密度 n，视分子为有效直径 d 的硬球。盯住一个以速率 v 运动的分子 A。

列依据。两条几何/统计前提：一是碰撞判据——两分子中心距离小于 d 即碰撞；二是把问题简化为”目标分子运动、其它分子静止”，之后再用相对运动修正（相对速率 2​vˉ）。

逐步演绎。第一步，算目标分子 A 在时间 t 内”扫过”的体积与碰到几个分子。把其它分子看成静止的点，则 A 扫出一个半径 d、高 vt 的圆柱，体积 V扫​=πd2⋅vt。圆柱内每有 n 个分子，A 就碰撞 nV扫​=nπd2vt 次。

第二步，求碰撞频率 Z（单位时间碰撞次数）：

Z=tnπd2vt​=nπd2v

第三步，引入相对运动的 2​ 修正。上面假设其它分子静止，但实际它们也在动，A 相对其它分子的平均速率是 2​vˉ（对麦克斯韦分布，相对速率与单分子平均速率之比为 2​）。用 2​vˉ 取代 v：

Z=2​πd2nvˉ

第四步，由”平均自由程 = 平均速率 ÷ 碰撞频率”：

λ=Zvˉ​=2​πd2nvˉvˉ​=2​πd2n1​

回头看。结论水到渠成：λ 的倒数正比于”碰撞截面 × 分子数密度”——碰撞越容易（截面大）、分子越密（n 大），λ 越短；2​ 是其它分子也在运动、使相对碰撞更频繁带来的修正。整个过程只用了”扫柱体积 + 碰撞判据 + 相对速率修正”，没有多余假设。尤其记住 1/πd2 中 πd2 是一个分子”挡住的路”，n 是”路上多密”，二者一乘就是”每米撞多少次”，取倒数即是”每撞一次走多远”。

为什么重要

平均自由程是气体动理论从”平衡统计”走向”输运过程”的枢纽量：

  • 决定输运快慢：扩散、黏性、热传导全靠分子碰撞传递动量、能量与质量。λ 大，则分子能携带一段距离的”信息”不被打断地传递，输运更有效率；λ 小，碰撞频繁、传递被打乱。三大输运系数都与 λ 成正比——它管着气体”传得快不快”。
  • 联系宏观与微观：由 λ 可反推分子有效直径 d（实测 λ/输运系数 → 得 d），是实验测定分子尺寸的经典手段。
  • 辨别真空与流动状态：当 λ 接近或超过容器尺寸时（低压真空），分子很少撞壁、运动由边界主导（克努森流/分子流），与常规”连续介质”流动截然不同——这在真空技术、微流控、航天上是关键判据。

工程动机：真空泵、镀膜、分子束、气体输运管道、微机电中的稀薄气体，都要先算 λ 与容器尺寸之比（克努森数），判断该按连续流体还是分子流处理。不掌握 λ，很多”气体在有限空间怎么运动”的问题会判定错模型。

尤其在高真空、微流控领域，λ 往往是”压气路的判据”；而在输运现象里，λ 又是衡量”分子一次性能把信息带多远”的关键——它一头牵着”空间的稀稠”，另一头牵着”输运与碰撞的节奏”，是连接”平衡态微观结构”与”非平衡传输速率”的最后一把钥匙。理解 λ，才算真正走进分子世界的”交通图”。

适用条件

平均自由程公式的成立有明确前提：

  • 分子视为硬球（有效直径 d）：λ 依赖硬球直径，真实分子有势、非刚球，d 是等效的”碰撞截面”近似。
  • 理想气体（稀薄、多为二体碰撞）：分子数 n 不太大，碰撞主要是两两碰撞；n 过大需考虑三体、尺寸效应。
  • 平衡态、大量分子：λ 是统计平均，须大量分子、无外场、分布稳定。
  • λ 远小于容器尺寸：若 λ 与容器尺度可比（低压真空），分子在飞完一个 λ 前就撞壁，这时”自由程”被容器边界限制，公式失效，需按分子流/克努森理论处理。

边界要说清：高压（分子自身体积占主导）、低压极稀薄（λ 大于容器）、非平衡强输运都会使 λ=2​πd2n1​ 明显偏差。真实边界：近临界态、真空度极高、强剪切流，均需更精细的分子动力学或克努森修正。

边界与误区

  • 误区一：以为 λ 是”分子的大小”。 根因：都带”程""径”，容易混淆。正确区别：λ 是分子两次碰撞间的飞行距离（约几十纳米），分子有效直径 d 才是分子本身尺寸（亚纳米）。两者差几个数量级，别混用。

  • 误区二：把 2​ 误解成”分子数翻倍”之类。 根因：看到一个 2​ 就联想某个数量。正确区别：2​ 来自其它分子也在运动，使”相对速率”比单个分子速率大 2​（相关系数修正），从而碰撞更频繁、λ 相应缩小。

  • 误区三：以为”等容加热”会增大 λ。 根因：觉得温度高、分子快，就以为自由程大。正确区别：等容加热时 n 不变，λ 只取决于 n 与 d2，故 λ 不变——变的只是碰撞频率 Z（分子快、撞得快）。要增大 λ 得减压或恒压升温，靠降 n 而非升温。

  • 误区四：忽略”λ 受容器尺寸限制”的情形。 根因：以为 λ 只由气体属性定，与容器无关。正确区别：在极低压下 λ 超过容器尺寸时，分子未飞满一个 λ 就撞壁，实际”自由程”被边界钳制，公式失效。真空泵、微型管道里必须考虑这层。

对照

最容易和平均自由程混的是平均碰撞频率 Z。两者只用一个关键差异区分：

λ 量”能走多远”，Z 量”每秒撞几次”。

λ=vˉ/Z 是距离，与数密度 n 成反比（∝1/n）；Z=2​πd2nvˉ 是频率，与密度和速率都成正比（∝nvˉ）。一句话记忆：λ 是”两步之间多长”，Z 是”每秒踏几步”——二者互为倒数关系（中间隔着 vˉ），一个管空间松弛、一个管时间节奏，但讲的是同一份碰撞的两种透视。

例子

我们把 λ 与 Z 实际算一遍，看常温常压空气碰撞有多疯狂。

室温 T=300 K、p=1.013×105 Pa 的空气，分子数密度 n≈2.5×1025 m−3，有效直径取 d≈3.6×10−10 m，平均速率 vˉ≈445 m/s。平均自由程：

λ=2​πd2n1​=2​×3.14×(3.6×10−10)2×2.5×10251​≈7×10−8 m=70 nm

平均碰撞频率：

Z=λvˉ​≈7×10−8445​≈6.4×109 s−1

每个空气分子每秒约被撞 64 亿次，每次只能自由飞约 70 纳米。

反推工程含义：这正是”分子飞快却扩散极慢""香水要慢慢飘”的根本原因——分子速度虽大，却几乎每飞几十纳米就撞一次、被迫转三千六百度乱向，宏观净位移被大幅拖慢。它从 λ 与 Z 的悬殊直观解释了气体扩散、黏性、热传导为何都以”很慢、很平缓”的方式发生：分子想传递一段距离的能量或质量，全靠这段被反复撞断的折线慢慢”接力”，而接力效率恰由 λ 决定。

把这笔账再往前推一步：若要增大 λ，工程上最直接的手段是降低压强（p↓⇒n↓⇒λ↑），这就是真空技术放大 λ 的物理逻辑。到 λ 赶上或超过容器尺寸（如厘米级真空），分子便”难得相撞”，转而频繁碰壁——气体行为从”碰撞主导”切换为”边界主导”，这正是高真空分子流的判据。从 λ 的数值，你不仅能读出碰撞多频繁，还能预判气体在有限空间里会以哪种”流态”运动。
