AHB/APB 分频总线

一句话定义

AHB/APB 分频器把系统时钟 SYSCLK 按固定系数逐级降频，得到 HCLK、PCLK1、PCLK2 三大总线时钟，让不同速度的总线域与外设各自拿到匹配的节拍。

定性

先给你一幅能”减速”的画面。你在山顶有一个压力很大的蓄水池，水压大得能推动大发电机（AHB），但山脚下一些小车间根本抵不住那么猛的冲击，得先装”减压阀”把水压降下来才敢进。于是你把一根主干分成几路：一路直接进 AHB 高速区（水压原封不动），一路过一挡”减压阀”进 APB2（降一点），再一路过两挡”减压阀”进 APB1（降更多）。每一个减压阀，就是一个分频器：它把进来的频率除以一个整数，输出一个更慢但比例精确的节拍。这一串”主干 → 几道闸 → 各速度区”的装置，就是总线的分频结构。它接在时钟树的分发层，上游是 时钟树与源选择 的 SYSCLK，下游则把 HCLK/PCLK1/PCLK2 交给 外设时钟门控使能 去逐个开关给外设。

真正反直觉的点是：不是”越快越好”，而是”各取所速”。芯片里有些区域能跑得快（CPU、SRAM、DMA 常在高速 AHB 域），有些区域硬是跑不快（低速外设、实时性要求不那么高的 UART/定时器在 APB1）。如果一股脑把 72MHz 灌给所有外设，那些跟不上 72MHz 的电路会出错；但反过来把所有外设都降到最慢，又浪费 CPU 的性能。所以分频器的存在，是把”一个很快的源”，聪明地适配成”多个不同速度的供应”——它是”让快的更尽情、让慢的不受伤”的那道缓冲。另一个反直觉点在于定时器：很多人以为 APB 外设拿到多少兆，定时器时钟就是多少兆，实际上 F1 有个”悄悄的优待”，看下文。

数学表达

从系统时钟 SYSCLK 出发，经过三组分频后得到三条总线时钟。F1 上的分频关系写为：

fHCLK​=AHB_PSCfSYSCLK​​,fPCLK2​=APB2_PSCfHCLK​​,fPCLK1​=APB1_PSCfHCLK​​

其中 AHB_PSC、APB2_PSC、APB1_PSC 分别是 AHB 预分频器、APB2 预分频器、APB1 预分频器的分频系数（取 1,2,4,8,16 等）。符号说明：fHCLK​ 是 AHB 总线时钟（Hz），CPU、内存、DMA 都在这一域；fPCLK2​ 是 APB2 的高级外设时钟（较快，如 ADC、GPIO、USART1）；fPCLK1​ 是 APB1 的低速外设时钟（较慢，如定时器、UART2/3、I2C、CAN）。

F1 的典型整定是：SYSCLK=72MHz，AHB_PSC=1，APB2_PSC=1，APB1_PSC=2，于是

fHCLK​=72MHz,fPCLK2​=72MHz,fPCLK1​=272​=36MHz

最后是那个”悄悄优待”：APB 域里的定时器时钟在 APB_PSC \ne 1 时会翻倍，即

fTIM​=2×fPCLK​

因为 APB1_PSC=2，所以 fPCLK1​=36MHz，而挂在 APB1 的定时器实际拿到 fTIM​=2×36=72MHz。读这条就知道：别把”外设分频后的总线频率”直接当成定时器频率，定时器经常比它所在的总线跑得还快，这正是那个”反直觉点”的数学本体。

关键性质

  • 频率逐级下降，绝不上跳：fHCLK​≥fPCLK2​≥fPCLK1​，因为分频只会除不会乘。为什么？分频器是计数器每数满 N 次输出一个脉冲，输出频率恒为输入除以 N，不可能大于输入。这保证”越往低速区，节拍越慢”，符合”慢外设配慢时钟”的意图。
  • APB 分频非 1 时，定时器时钟翻倍：这是 F1 外设时钟里最容易被忽略的一条。为什么？因为许多定时器设计成在 APB 域但需要更高时钟来计数，芯片于是加了个”分频非 1 即 ×2”的规则，让定时器时钟能补齐到接近 AHB 的水平。若 APB_PSC=1，定时器时钟就等于 fPCLK​；若 APB_PSC=2/4/…，定时器时钟是 fPCLK​×2。搞不清这条，定时器算出来的延时/频率会凭空差一倍。
  • 分频系数不是”随便配”，受外设上限约束：PCLK1 的最大值（F1 为 36MHz）、PCLK2 的最大值（F1 为 72MHz）决定你该怎么分。为什么受限？APB1 的低速外设跟不上高频，芯片给它们定了一个频率天花板（比如 36MHz），分频必须保证不超出。设错了，外设在过快节拍下工作，时序失稳甚至功能异常，而故障表现往往隐蔽。
  • 分频链路是”树”的纵向部分，与选源是不同维度：选源（SW）是横向”选哪一口”，分频（AHB/APB_PSC）是纵向”降多少倍”。为什么？因为主干只有一个来源，但要把这一个速度发往多个速度不一的域，必须纵向逐级降档。二者一条横向一条纵向，共同织出”从源到外设”的完整分发网络。
  • 所有外设时基都从这三大时钟派生：UART 波特率、SPI 速率、定时器时基、I2C 时钟，全部以某一条总线时钟为源头再细化。为什么？外设内部往往有各自更深层的分频，但最上游总归是 HCLK/PCLK1/PCLK2 之一。改动了分频系数，等于全局性地改了所有下游时序——这也是为什么”改一个系统时钟，很多外设全失效”的缘起。

推导

先抛一个问题：为什么系统时钟一个就够，非要用分频拆成 HCLK、PCLK2、PCLK1 三条，还各有不同的速度？如果直接把 72MHz 灌满全局，“快外设”岂不都能受益？我们要从”不同电路对时钟上限截然不同”这一事实，第一性推出分频的必要性和分布规律，并顺带解开”定时器为何翻倍”的谜。

设物理场景。芯片内部有三类电路：一是 CPU/内存这类”高速逻辑”，逻辑门延迟短，可以吃下高时钟；二是如 ADC、高速串口这类”较高速度外设”，需要不太低的时钟但有一定上限；三是如普通 UART、I2C、CAN 这类”低速/容错外设”，它们的内核结构（较深的组合逻辑、时序余量小、抗干扰设计）决定它们经不起太高的时钟。三类的可承受频率是：fmaxAHB​>fmaxAPB2​>fmaxAPB1​。我们给它们接在三条总线上。

列依据。用两条已确立的数字设计准则。一是逻辑门延迟与时钟的关系：一个数字电路的”最高可运行频率”由它最关键的路径延迟决定，fmax​≈1/tpath​；路径越深、延迟越大，能容忍的时钟越低。二是分频器定义：一个 N 分频器输出频率是输入的 1/N，且分频比精确、不改变相位频响（仅按整数折半）。这两条是电气原理，不是偏好。

逐步演绎。先把”全高速”方案否决。若把 72MHz 灌给 APB1 的低速 UART，它关键的组合逻辑路径 tpath​ 较大，1/tpath​ 只支持比如 36MHz；72MHz 远超其能力，数据无法在下一个沿前稳定，出现建立违例，误码或乱数据。为了保住这类外设，必须给 APB1 一个低时钟，于是引入 APB1_PSC 分频：取 N=2，得到 fPCLK1​=72/2=36MHz，恰好压在外设可承受线内。同理 APB2 的较快外设可承受更高（72MHz），故 APB2_PSC=1 不降；AHB 域让 CPU 全速，AHB_PSC=1。于是”逐级递减”的分布就由”各域外设各自的可承受上限”倒推出来——不是随意抓的分，而是按每个域的 fmax​ 定的。

再解”定时器翻倍”。定时器既想跟高速 AHB 域同频（计数更精细），又不得不挂在 APB 域（受总线管理）。芯片的折中办法是：当 APB_PSC \ne 1（即 APB 确实降了速）时，给定时器单独 ×2，把定时器时钟补回 2×fPCLK​，抵消”降速对定时器的拖累”，使它接近 AHB 速度。以 F1 为例：APB1_PSC=2 使 fPCLK1​=36MHz，定时器补 ×2 后 fTIM​=72MHz——定时器因此还能跟 CPU 同速计数，PWM 和输入捕获的频率分辨率不被牺牲。

回头看。我们用”逻辑路径延迟决定最高频率”和”分频器按整数折半”两条，推出了三个必然结论：其一，分频系数由各外设的可承受上限决定，陡升陡降不成——必须把快源按各域慢速降档。其二，分布是逐级递减的（HCLK≥PCLK2≥PCLK1），因为分频只除不乘，且各域上限本是递减序列。其三，定时器是例外而必要——它靠”APB 非 1 即 ×2”拿到比总线还高的时钟，避免”降速拖累计数精度”。这三条一起解释了：为什么时钟树要三级分频、为什么你要背”PCLK1 上限 36MHz”、又为什么算定时器频率前要先看一眼 APB 分频是不是 1——它们都是”不同电路对速度上限不同”这一物理事实的数学生成物。

为什么重要

AHB/APB 分频决定了”芯片里每一个区域跑多快”，它是把单个系统时钟适配成全芯片多样化背景的核心，也是所有外设时基的根。最直接的后果是外设可用上限：PCLK1 被限在 36MHz，若你把分频设错让 APB1 超频，UART/I2C 会误码乱时序，而故障往往隐蔽为”偶尔错一个字”。第二个后果是性能与稳定性平衡：AHB 域若不降、APB 域若不降，快外设受损；全降又让 CPU 饿着——分频是”让快的舞、让慢的歇”的资源配置。第三个后果是时基链全局联动：UART 波特率、SPI 速率、定时器周期、CAN 位时序，全部从这三条总线时钟派生；你改一个分频系数，下游所有外设的时基跟着变，这就是”改一处、挂一片”的根源。工程上所以把分频整定当作时钟树的”目标态”来背：F1 若要 PCK1=36MHz、PCLK2=72MHz，就必然要配 AHB_PSC=1、APB2_PSC=1、APB1_PSC=2，这个组合写在标准外设库的时钟初始化里，几乎每个工程都用它。分清这三个域、记住各自的频率上限、以及定时器”非 1 即 ×2”，是配置外设（尤其定时器、串口）不出错的第一步，也是排查”频率怎么差一倍”类疑惑的钥匙。

适用条件

  • 分频器适用于”同一个源要喂多种速度电路”的场合：只要芯片内存在快慢不一的总线域（AHB/APB2/APB1），就必须分频。为什么受限？它要求你清楚每个域的上限，并保持”逐级不跳档”，否则要么超频外设、要么浪费 CPU。
  • 对各域频率上限一致的前提：必须遵守芯片数据手册的 f_{PCLK1}、f_{PCLK2} 最大值（F1 为 36/72MHz）。为什么受限？这些上限是芯片设计时按路径延迟与功耗定的，盲目超限会让外设时序失稳，且常无显式报错，最难查。
  • “APB 非 1 即 ×2”只针对定时器时钟：这条规则适用并只适用于 APB 域的定时器（TIM），不适用于同域的其他外设。为什么？因为只有定时器需要高计数频率来保精度；若不是定时器，直接按 fPCLK​ 算即可。
  • 与选源配合而非替代：分频在”源选择（SW）“之后执行，它不回答”用哪路”，只回答”降到多少”。为什么受限？因为若主干自身都没选对（比如还跑 HSI 8MHz），分频算得再对也白搭；先定源、再定分频，顺序不可颠倒。

边界与误区

  • 误区一：以为所有外设都希望”越快越好”，于是不分频。根因是”频率高 = 性能强”的直觉，把 CPU 的喜好套到外设上。正确的是慢外设过频会出错；APB 分频正是为了保护那些跑不满高速的低速电路。越高速未必越好，而是”匹配才好”。
  • 误区二：把总线频率直接当定时器时钟。根因是看到 fPCLK1​=36MHz 就认为定时器也是 36MHz。正确的是：APB 分频非 1 时，定时器时钟是本总线 ×2，即 APB1_PSC=2 时长定时器实际拿 72MHz。只记总线频率，定时器算出的频率会差一倍。
  • 误区三：以为分频系数可以随意组合。根因是代码里填 AHB_PSC、APB_PSC 就像填参数，多大多小都”能编译”。正确的是受各域上限约束，且结果必须落在外设可承受范围；否则编译不报错、运行才出错，属”隐性故障”。
  • 误区四：以为改动系统时钟只影响 CPU。根因是”系统时钟”名字只带”系统”二字，仿佛只关 CPU。正确的是所有外设时基都是它分频派生的，改一次分频 = 所有外设时序瞬间全变，原配好的波特率、PWM 周期全部失效。“改一震一片”是分频链联动的必然结果。

对照

与”AHB/APB 分频（除法）“最容易混淆的是 PLL（乘法）。两者一起构成时钟树的”一乘一除”，但方向相反。关键差异在于：PLL 做的是乘法（把源 ×N 往高拉，放大系统速度），分频做的是除法（把系统频率 ÷N 往低降，迁就慢外设）。一句话回答”什么时候用谁”：当你想”把慢晶振提到 CPU 全速”时用 PLL；当你想”把已经很快的系统时钟降下来，喂给跑不了那么快的总线和外设”时用分频。前者放大、后者分配；前者决定”能跑多快”，后者决定”各域分到多少”。二者在一条链上前后相接（源 → PLL 乘 → 总线分频除），用口诀记：PLL 是油门，分频是变速箱——先踩油门提速，再挂不同的档位把速度分配给各个组件。

例子

我们算一遍，把 AHB/APB 分频落到具体数上。设 F103，SYSCLK = 72MHz。

第一步：定 AHB 域。 AHB_PSC = 1，CPU、内存、DMA 全速：

fHCLK​=172​=72MHz

第二步：定 APB2。 高速外设（ADC、GPIO、USART1）可承受较高，APB2_PSC = 1：

fPCLK2​=172​=72MHz

第三步：定 APB1。 低速外设上限 36MHz，APB1_PSC = 2：

fPCLK1​=272​=36MHz

这三步能直接解释为什么”系统时钟 72MHz”时，挂在 APB1 的 USART2 波特率计算里，时钟源是 36MHz 而不是 72MHz——挂在不同域的外设，拿到的时基天然不同。若有人把它写成 72MHz，串口波特率会整体偏 2 倍，收发全错。

再看定时器。 取挂在 APB1 上的 TIM2，APB1_PSC = 2 \ne 1，于是：

fTIM2​=2×fPCLK1​=2×36=72MHz

也就是说 TIM2 虽在”36MHz 的 APB1 域”，计数时钟却和 CPU 一样是 72MHz。若你按”总线频率 36MHz”去算 PWM 周期，算出的占空比、频率就偏离实际的 72MHz，整整差 2 倍。这层”×2”很容易被忽略，是定时器类故障的常见根源。

反推工程含义： 设分频前，先问”我这个外设挂在哪条总线、那条总线的上限是多少、它的定时器要不要 ×2”，这三问决定你应填的分频系数与后续算法里的时钟代入值。把第一问做错，外设过频误码（APB 超限）；把第三问做错，定时器差 2 倍（忘了 ×2）。分频这件事，图省事选错一位，就能让一整片外设的时基系统性偏移。
